# 대학원 AI 논문 연구 도우미 (v3.2.0)

논문을 찾아 읽고, 연구 기여도와 증명방법을 정리해 A4 과제 보고서로 내려받고, 본인의 의문을 연구계획과 논문 초안으로 발전시키는 Streamlit 웹앱입니다.
AI는 읽기를 돕는 초안을 만들 뿐, 연구 결과나 본인의 의견을 대신 만들지 않습니다.

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 01. 자료 찾기 | 국회도서관 자료검색 API 검색, 자료유형 자동분류(학위논문→학술기사→도서자료→미확인), 대분류·자료 선택, 정식 참고문헌, 대학 저장소 링크 |
| 02. 논문 읽기 | PDF 본문 추출, **페이지별 읽기(튜터)**, **쪽별 요약과 쪽별 메모**(생각해 볼 점의 답, 메모 AI 문장 완성), **논문에 질문하기**, 과제용 6항목·읽기용 7문장 요약, 기여도·증명방법 3줄, 근거 문구 원문 대조, 나의 생각 세 칸과 **칸별 실마리 질문**, **양식을 고를 수 있는** A4 보고서(Word·한글), 논문 삭제 |
| 03. 선행연구 분석 | 논문 비교표, 본인 의문에서 출발한 연구 아이디어 3개, 채택 |
| 04. 연구 방향·계획 | 연구 조건, 연구계획서, RQ 연결표, 변경 이력, **나의 연구 설계안(Research Paper) 장별 인터뷰·초안·초록, 표 포함 Word·한글** |
| 05. 연구 수행·분석 | CSV·Excel 점검, 전처리 기록, 결과표·그래프, 실험 기록 |
| 06. 내 논문 작성 | 장별 원고, AI 제안(자동 반영 안 함), 검토, Markdown·Word·한글 내보내기 |
| 관리자: AI 품질평가 | 평가 데이터셋, 규칙 검사, RAGAS 충실도, 사람 검토, 실행 비교, 결과표 |

## 로컬 실행 (Windows)

```
pip install -r requirements.txt
copy .streamlit\secrets.toml.example .streamlit\secrets.toml   (값을 채움)
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 폴더 전체를 GitHub 저장소에 올립니다. `.streamlit/secrets.toml`은 올리지 않습니다 (`.gitignore`에 들어 있음).
2. share.streamlit.io → Create app → 저장소·브랜치 선택, Main file path는 `app.py`.
3. Advanced settings → Secrets에 아래를 붙여 넣습니다.
   ```
   DATA_GO_KR_API_KEY = "공공데이터포털 인증키"
   ADMIN_PASSWORD = "관리자 메뉴 비밀번호"
   REVIEWER_PASSWORD = "검토자 비밀번호(선택)"
   ```
4. 배포 후 왼쪽 위의 버전·빌드 표시가 `core/version.py`의 값과 같은지 확인합니다.
5. 원우에게는 앱 주소만 공유합니다. 각자 OpenAI 키를 왼쪽에 넣어야 AI 요약이 동작합니다.

기존 앱(graduateresearchpaperlab.streamlit.app)을 바꾸지 말고 새 저장소·새 주소로 먼저 배포해 확인한 뒤 교체하세요.

## 키 두 가지

- `DATA_GO_KR_API_KEY`: 운영자가 Secrets에 넣는 공공데이터포털 인증키. 논문 검색에만 씁니다.
- OpenAI API 키: 이용자가 화면 왼쪽에 넣는 개인 키. 브라우저 세션에만 있고 서버·파일·로그에 저장하지 않습니다.

## 저장 방식

로그인과 서버 저장소가 없습니다. 작업은 브라우저 세션에만 있으므로 왼쪽 ‘프로젝트 저장·불러오기’에서 JSON으로 내려받아 보관합니다.
프로젝트 파일에는 API 키와 PDF 본문이 들어가지 않습니다. 불러온 뒤에는 PDF를 다시 올려야 합니다.
관리자 평가자료도 같은 방식으로 세션에만 있으며 데이터셋 파일로 내려받아 보관합니다.

배포 후 처음 할 일: 실제 키로 ‘데이터베이스 포렌식’을 검색해 ① 제목·저자가 제대로 나뉘는지 ② 학위논문 분류가 맞는지 ③ ‘검색 진단’의 수신 건수가 맞는지 확인합니다.
DB 값이 예상과 다른 이름으로 오면 `core/nanet.py`의 `classify()`를 실제 값에 맞춥니다.

## v3.2.0에서 바뀐 것 (아티팩트의 새 기능을 모두 반영)

- **페이지별 읽기** (02-② 첫 탭): 왼쪽에 PDF 쪽 그림, 오른쪽에 튜터. 쪽마다 읽을 범위와 질문 2~3개 → 힌트(한 줄 힌트 → ① 위치 ② 주목할 표현 ③ 빈칸 문장 ④ 빈칸을 채운 문장) → 내 답 확인 → 2~3문장 요약 피드백(정확한 점·꼭 보완/더하면 좋음·고칠 곳·오탈자). ‘요약 틀 도움’ 뒤 ‘틀 채우기’를 누르면 원문에서 찾은 답과 근거 문구(원문 대조 표시), 채운 틀, 이은 요약을 보여 주고 ‘내 요약 칸에 넣기’로 넣을 수 있습니다. 모범 요약은 직접 눌렀을 때만 보이고 자동으로 넣지 않습니다. ‘처음부터 차례로’와 ‘중요 페이지만’(AI가 읽을 쪽을 고름) 두 방식, PDF 쪽/인쇄 쪽수 자동 대응과 확인, 모르는 용어 설명이 있습니다. 피드백에서 꼭 보완할 점이 없으면 그 쪽을 ‘끝냄’으로 표시하고 요약을 쪽별 메모에 넣습니다.
- 쪽별 요약: ‘생각해 볼 점’의 답(그 쪽 원문 근거)을 접어서 보여 주고, 페이지별 읽기를 끝낸 쪽은 펼쳐 둡니다. 이전에 만든 요약에는 ‘논문 근거로 답 보기’ 버튼이 나옵니다. 메모를 쓰면 ‘AI로 문장 완성’ → 미리보기 → 사용/버리기 → 되돌리기.
- 나의 생각 세 칸: 직접 쓴 메모를 ‘AI로 완성하기’로 문장으로 다듬습니다(실마리 질문 반영, 메모에 없는 경험은 만들지 않음). 미리 보고 ‘사용’을 눌러야 칸에 들어가며 되돌릴 수 있습니다.
- 보고서 ④: ‘페이지별 읽기에서 끝낸 내 요약으로 연구 개요 만들기’.
- 04 메뉴 ‘나의 연구 설계안’ 탭: 초록·주제어, Ⅰ 서론 ~ Ⅵ 결론, 참고문헌 양식. 장마다 AI 인터뷰 질문(또는 AI 없이 기본 질문) → 내 답 → 장별 초안(소절·문단·표를 화면에서 바로 고침, 이전 초안 되돌리기) → 초록·주제어·제목 후보 → 미리보기와 Word·한글 내려받기. 표 번호는 자동으로 매깁니다.
- Word·한글 파일이 소제목, 표 제목, 표, 주제어, 참고문헌 줄을 지원합니다.
- 페이지 그림은 이 세션에서 올린 PDF로만 그립니다(서버에 저장하지 않음). 프로젝트 파일을 불러온 뒤에는 같은 PDF를 다시 올리면 페이지별 읽기 진행 상황이 이어집니다.

## v3.1.1에서 바뀐 것

- 배포할 때 일부 파일만 새 버전으로 바뀌면, 화면 맨 위에 어느 파일이 이전 버전인지 빨간 안내가 나옵니다. 모든 파일을 다시 올리고 Manage app → Reboot app을 누르면 사라집니다.
- AI 기능에서 예상하지 못한 오류가 나도 화면 전체가 멈추지 않고 그 자리에 안내만 표시합니다.

## v3.1.0에서 바뀐 것 (논문 요약 보고서 도우미 아티팩트와 맞춤)

- 쪽별 요약: PDF를 6쪽씩 나눠 쪽마다 1~2문장 요약, 핵심 용어, 생각해 볼 점을 만듭니다. 실패하면 남은 쪽부터 이어서 요청합니다. 본문 쪽마다 메모 칸이 있고, 메모를 ‘생각과 의문’ 칸에 `[p.N] 메모` 형태로 모읍니다.
- 질문 예시 받기: 선정 이유·생각과 의문·추가 검토점 세 칸 아래에 실마리 질문을 따로 붙입니다. 칸에 자동으로 옮기지 않습니다. 선정 이유와 추가 검토점 입력은 ③으로 옮겼습니다.
- 논문에 질문하기: 논문 원문을 근거로 답하고 근거 쪽을 [p.N]으로 붙입니다. 대화는 논문별로 프로젝트 파일에 저장됩니다.
- 보고서 양식: 기본·간단·상세 또는 직접 구성(항목 켜기·끄기, 순서, 제목). 프로젝트의 모든 논문에 적용됩니다.
- 이전 버전에서 내보낸 프로젝트 파일은 불러올 때 새 항목이 빈 값으로 채워집니다.
- 아티팩트의 ‘계정에 자동 저장’은 이 앱에 없습니다. 로그인 기능이 없어 지금처럼 프로젝트 파일(JSON)로 보관합니다.

## 아직 정하지 않은 것 (기본값으로 둔 것)

- 6항목 요약 길이: 항목당 한 문장
- A4 보고서: 한 쪽 기준 약 1,600~1,800자 안내만 하고 강제하지 않음
- 품질평가 기준 점수 0.8, 한 번에 30사례: 관리자 설정에서 바꿀 수 있는 임시값
- PDF 한도: 40MB, 400쪽. AI 전송 한도: 약 9만 자 (넘으면 쪽마다 앞뒤 일부만 전송하고 화면에 표시)

## 지원하지 않는 것

스캔 PDF 글자 인식(OCR), 그림 속 그래프 분석, 고급 통계·모형, 검색 문맥(RAG) 정밀도·재현율 평가, Agent 평가, 학교 제출 시스템 자동 제출, PDF 보고서 출력.
